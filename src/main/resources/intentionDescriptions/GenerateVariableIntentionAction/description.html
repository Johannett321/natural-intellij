Adds a missing variable declaration to the DEFINE DATA section.

Place the caret on an unresolved variable reference and invoke this intention to jump to the correct location and insert a new variable declaration with a live-editable data type.

Simple variable (e.g. #COUNTER) — inserts a level-1 declaration into the first inline block (LOCAL, GLOBAL, or PARAMETER) of the current file.

Qualified variable (e.g. SAK.VARNAME) — locates the group SAK in the current file or in an imported data area file (LOCAL USING SAK), then inserts the new field at the correct nesting level directly in that file.
